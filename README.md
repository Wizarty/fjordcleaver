# 🚜 FJORDCLEAVER — Cozy Isometric Low-Poly Snow-Plowing

## 🌟 Особенности игры / Game Features

- **🚜 Реалистичная деформация снега**: отвал снегоуборщика начисто срезает сугробы до теплого асфальта, булыжной мостовой, деревянных настилов и чистого озерного льда. При поворотах снег не насыпается обратно, а чисто исчезает.
- **🧊 Чистый озерный лед**: на озерах и реках нет сугробов — это гладкий кристальный лед со скольжением и дрифтом.
- **🏛️ Цель игры — спасение и сопровождение в Город (Fjordhaven Refuge)**:
  - В центре долины расположена городская площадь с ратушей, больницей скорой помощи, уличными фонарями, горячим супом и костром.
  - Спасенные из сугробов автомобили и жители **могут передвигаться только по расчищенным дорогам** (алгоритм A* / BFS).
  - Если на пути снег — они останавливаются и зовут на помощь. Когда вы прокладываете им дорогу к городу, они благополучно добираются до площади, принося награды и очки!
- **🛍️ Магазин скинов и тюнинга за кристаллы (Shop)**:
  - 4 уникальных скина машины: *Hearth Orange*, *Alpine Pine*, *Solar Melt Gold*, *Cryo Glacier*.
  - Эффекты снежного шлейфа: *Белый снег*, *Золотые искры*, *Аврора Неон*.
  - Цвета мощных фар: *Янтарный Галоген*, *Ксенон Неон*, *Аврора Изумруд*.
- **⏸️ Полноценное меню паузы**: горячие клавиши `Esc` / `P` или кнопка `⏸️` в верхнем меню с детальной статистикой долины.
- **📱 Адаптивное управление**:
  - **Десктоп**: `WASD` / Стрелки (или следование за курсором мыши), `Пробел` — Рывок (Dash), `E` — Термальный импульс (Melt), `Tab` — Мастерская/Магазин, `H` — Гудок/Радар, `Esc` / `P` — Пауза.
  - **Смартфоны и планшеты**: плавающий виртуальный джойстик в любой точке левой половины экрана + эргономичные радиальные кнопки действий под правый большой палец с тактильной отдачей (haptic feedback).

## 🛠️ Технологии

- **Single-file Web App**: чистый HTML5 Canvas + Tailwind CSS + Web Audio API без сторонних тяжелых библиотек.
- **Offline & Sandbox Safe**: 100% автономная работа без серверов и зависимостей.
