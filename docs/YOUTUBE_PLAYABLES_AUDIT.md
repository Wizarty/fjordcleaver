# YouTube Playables: предварительная проверка FJORDCLEAVER

Дата проверки: 23 октября 2026 года.

**Полная построчная проверка действующих официальных требований НЕ завершена.** Запросы к `developers.google.com` и SDK-домену блокируются сетевой политикой окружения (`403 Forbidden` / `CONNECT tunnel failed`). Это не отказ YouTube принять игру и не результат сертификации. Нельзя заявлять соответствие всем пунктам, пока не прочитан актуальный полный список и не пройден настоящий SDK Test Suite.

Ниже — матрица проверенных областей, а не выдуманная нумерация официальных требований. «Проверено» означает локальную проверку указанным способом. Тесты с mock SDK не заменяют YouTube, Safari, Android/iOS и проверку модератором.

## Источники и границы проверки

Официальные источники, доступ к которым необходимо восстановить:

- [Официальный раздел YouTube Playables](https://developers.google.com/youtube/gaming/playables).
- [SDK Reference](https://developers.google.com/youtube/gaming/playables/reference/sdk).
- [SDK Test Suite](https://developers.google.com/youtube/gaming/playables/test_suite).
- [Требования монетизации](https://developers.google.com/youtube/gaming/playables/certification/requirements_monetization), если позднее будут добавлены реклама или вознаграждения за её просмотр.

Доступные вторичные технические источники, по которым сверены URL SDK и используемые API:

- [Phaser Playables template, commit 3fb2cf0](https://github.com/phaserjs/template-youtube-playables/tree/3fb2cf010c8169fed969a7256e40d499b67cfbda), `index.html`, `src/YouTubePlayables.js`.
- [Defold Playables extension, commit b1122a7](https://github.com/defold/extension-playables/tree/b1122a7a81dd23a573856a263003c3dcebf2cbb5), `docs/index.md`, `playables/lib/web/lib_playables.js`.

Это примеры разработчиков движков, **не официальный текст правил Google**. Зафиксированные ими API необходимо дополнительно проверить против актуального SDK. SDK не копировался и не подменялся в сборке; ZIP подключает оригинальный `https://www.youtube.com/game_api/v1` первым скриптом. Подмена используется только в явно обозначенных локальных тестах.

## Результаты текущего прогона

- 21 автоматический тест пройден (14 игровых и 7 SDK/упаковочных с mock SDK).
- Карьерный прогон: 197.85 simulated minutes, все семь веток достигли уровня 6.
- Save data в конце прогона: 105 288 байт при подсчёте UTF-16 (`length × 2`).
- Итоговый ZIP: 60 080 байт. Это измерения, а не официальные нормативные лимиты.

## Воспроизведение

```sh
python3 -m unittest discover -s tests -v
python3 tests/benchmark_career.py
python3 tools/build_playables.py
```

Playwright и Chromium нужны только для проверок. В игре нет npm/Python-зависимостей. Сборка создаёт `artifacts/fjordcleaver-playables.zip`; это кандидат для проверки, а не одобренный YouTube релиз. Не нужно отправлять весь GitHub checkout или использовать обычный Pages HTML как готовый SDK-архив.

Короткий headless Chromium замер 30 кадров, после оптимизации (23.10.2026):

| CSS viewport | Средняя частота | Медиана интервала | p95 интервала |
|---|---:|---:|---:|
| 390×844 | 60.0 fps | 16.7 ms | 16.7 ms |
| 1280×900 | 54.4 fps | 16.7 ms | 33.3 ms |
| 844×390 | 60.0 fps | 16.7 ms | 16.8 ms |

Это короткая диагностическая выборка на облачной машине, не замер на телефоне. С ней нельзя утверждать прохождение всех performance-требований или стабильность многочасовой сессии. Точные нормативные пороги, лимиты ZIP/save data, временные ограничения SDK и поддерживаемые версии ОС/браузеров нужно взять из доступной актуальной официальной документации.

## Что остаётся сделать

1. Применить сохранённые в черновик домены `developers.google.com` и `www.youtube.com` в настройках облачного окружения. Сохранение черновика само по себе не меняет действующую сеть и не публикует окружение.
2. Прочитать весь действующий официальный список; заменить эту матрицу точной сверкой каждого нормативного пункта и устранить новые расхождения.
3. Запустить ZIP с настоящим SDK Test Suite, проверить init/readiness, pause/resume, audio, save/load на аккаунте YouTube, offline/error/reload и разрешённые сетевые обращения.
4. Выполнить проверки Android/iOS/desktop на требуемых устройствах, включая несколько часов игры, рост памяти, вырезы и смену приложения. При подтверждённом росте памяти ограничить cache chunks с сохранением незавершённых эвакуаций.
5. Подтвердить права и возрастную категорию, подготовить материалы и метаданные по порталу и пройти review. Само наличие GitHub Pages не даёт права/доступа публиковать Playables.
